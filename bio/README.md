# Bio & CV Materials

Templates and reference docs for grant applications, conference CFPs, and accelerator applications.

## Files

| File | Purpose |
|---|---|
| [`cv-zh.md`](./cv-zh.md) | 1-page Chinese CV — for g0v, OCF, moda applications |
| [`cv-en.md`](./cv-en.md) | 1-page English CV — for Anchor Taiwan, international audiences |
| [`bio-short.md`](./bio-short.md) | Three lengths of bio (50/150/300 words) — for speaker submissions, social, etc. |
| [`headshot-checklist.md`](./headshot-checklist.md) | What kind of photo you need + where to use which version |

## Important: these are TEMPLATES

Every CV file has `⟨placeholder⟩` markers where personal information goes. **Do not submit any of these files as-is.** Fill in:

- Full legal name (中文 + English)
- Date of birth, ARC/passport number (only for grants that require it)
- Past employers, dates, titles, scope
- Education
- Specific past projects and outcomes
- Real contact email + phone

## What's pre-filled (don't change)

- Taiwan UI project description and current statistics
- Core philosophy / approach descriptions
- Anything that's a fact about the public state of the repo

## Maintenance

Update these whenever:
- Taiwan UI hits a new milestone (npm publish, new component count, stars threshold)
- You complete a major past role at a new employer
- Grant programs request a new format you don't already have
