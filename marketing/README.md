# Marketing & Launch Copy

Ready-to-paste copy for the Forge launch sequence. Run these in roughly this order over 2–3 weeks.

## Files & order

| File | Channel | When to post |
|---|---|---|
| [`01-threads-launch.md`](./01-threads-launch.md) | Threads / X | Day 0 — your launch day |
| [`02-g0v-slack-intro.md`](./02-g0v-slack-intro.md) | g0v Slack `#general` | Day 0–1 (after the public post) |
| [`03-hn-show.md`](./03-hn-show.md) | Hacker News "Show HN" | Day 1–2 (Tuesday or Wednesday morning Taiwan time = Monday/Tuesday US time) |
| [`04-ithome-article.md`](./04-ithome-article.md) | iThome / Medium / personal blog | Day 7 (after initial buzz) |
| [`05-coscup-cfp-abstract.md`](./05-coscup-cfp-abstract.md) | COSCUP CFP submission | When CFP opens (typically Feb–April) |

## Why this sequence

1. **Threads first** — your warmest audience. Friends + Taiwan tech community amplify it
2. **g0v Slack second** — the most credibility-relevant audience. Their endorsement = grant readiness
3. **HN third** — global reach but harder. Best done after you have ~50 stars from steps 1–2 so HN visitors land on a repo with social proof
4. **Long-form fourth** — converts initial buzz into evergreen SEO traffic
5. **Conference fifth** — CFPs run on a separate clock; submit when they open

## DO NOT post all at once

If you fire all five in one day, it reads as "marketing campaign" and converts worse than the same posts spread over 2 weeks. Let each piece do its work before stacking the next.

## After launch — how to handle traffic

Pin a comment on each post:

> Discussion welcomed. Open issues at github.com/LawrenceKuok/taiwan-ui or join us in g0v Slack `#taiwan-ui` (channel coming soon).

Bookmark and respond to **every** thoughtful comment within 24 hours. The first 50 conversations shape the project's perception more than the next 5,000.

## Tracking

After each post, add a row to [`metrics.md`](./metrics.md):

- post URL
- date
- engagement numbers at 24h / 7d / 30d
- new GitHub stars / npm downloads attributable
- best comment / criticism received

This data goes into your grant applications.
