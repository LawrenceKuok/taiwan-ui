# Grant Funding History

Public record of grant funding received by Forge. Maintained for transparency and to fulfill grant program reporting requirements.

> Grant **applications** (drafts and submissions in flight) are tracked separately in [`grants/SUBMISSIONS.md`](./grants/SUBMISSIONS.md). This file lists only **approved and disbursed** funding.

## Grants received

_None yet. First entries will land here as the project applies for and (hopefully) receives grants from g0v, OCF, moda, and similar programs._

## Format for new entries

When a grant is approved, add an entry following this format:

```
### [Grant program name] — NT$[amount] — [decision date]

- **Funder**: [organization]
- **Cycle**: [year + round if applicable]
- **Period of performance**: [start date — end date]
- **Stated deliverables**:
  1. [deliverable 1]
  2. [deliverable 2]
- **Status**: [in progress / completed / extended]
- **Public report**: [link once published]
```

## Reporting commitment

For every grant received, this project commits to:

1. **Quarterly progress updates** posted publicly (Threads, blog, or g0v hackpad)
2. **Final project report** within 30 days of the funded period ending, including:
   - Itemized expenditure
   - Deliverables shipped vs. promised
   - Hours invested
   - Lessons learned
3. **Public release** of any deliverables produced under the grant (already mandated by MIT license, but stated explicitly here)

## Grant ethics

Forge commits to:

- Not double-claiming the same deliverable across multiple grants
- Not using grant money for personal expenses unrelated to project deliverables
- Disclosing all grant sources in any conference talks, articles, or public materials describing the project
- Returning unspent grant money rather than finding ways to consume it

This standard applies regardless of whether the grant program technically requires it.
