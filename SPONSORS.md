# Sponsoring Taiwan UI

Taiwan UI is open-source under MIT — free to use, modify, and embed in commercial products. There's no paid tier, no enterprise edition, no consulting upsell. Everything is in the public repo.

That makes sustainable maintenance the central problem.

This document explains how individuals and organizations can contribute funding so the project keeps shipping. **No sponsorship is required to use Taiwan UI.** Sponsorship buys the project sustainability — not access.

## Why sponsor

If your team or product depends on Taiwan UI to validate Taiwan-localized form inputs, sponsoring helps ensure:

- **Continuous spec-tracking** — when 戶政司, 財政部, NCC update their published rules (e.g. the 2021 ARC format change), validators ship within days, not months
- **Maintained CI quality** — 157+ tests stay passing, security headers stay current, dependencies stay patched
- **Government API server-side wrappers** (v0.3) — `lookupCompanyByTaxID` and similar — ongoing maintenance against API drift
- **Bilingual documentation** — content stays current as the API surface grows
- **Faster issue response** — currently best-effort within 7 days; with sustained funding can become 24–72h
- **Honest scope discipline** — `GOVT_READINESS.md` is updated as the project earns more credibility

### Today (pre-v0.2)

If you'd like to sponsor before the formal sponsorship channels are live, **open a GitHub issue** titled `[sponsor] [your-org]` describing your interest. The maintainer will reach out directly to set up arrangements.

## Tier benefits (post-v0.2 plan)

All tiers are recognition only — no functional gating of features.

### Individual ($5–25 /mo or one-time)

- Name listed in `BACKERS.md` and on the website footer
- Discord (when launched) early-supporter role

### Team ($50–250 /mo)

- All individual benefits
- Logo on the project README (small)
- Logo on the website footer

### Production ($500+ /mo)

- All team benefits
- Logo on the README (prominent)
- Logo on the website homepage
- Quarterly roadmap input call (30 min) with the maintainer
- Acknowledgment in conference talk credits
- Right of first refusal on consulting engagements (if/when offered)

### Founding (one-time $5,000+)

- Permanent acknowledgment in `BACKERS.md` as a founding sponsor
- Custom acknowledgement format
- Direct line to maintainer for issue prioritization (best-effort)

## Transparency commitment

When sponsorship is active, this project commits to:

- Publishing a **quarterly funding-and-spending report** (gross income, expense breakdown, hours of maintainer time, deliverables shipped)
- Listing all sponsors at every tier in `BACKERS.md` (unless they opt out)
- Never gating features behind sponsorship — sponsors get credit, not access
- Never accepting sponsorship that would compromise the open-source license or scope honesty

## What sponsorship does NOT buy

- Custom features that aren't in the public roadmap (those are paid consulting; separate)
- Faster issue response than the published SLA
- Removal of `GOVT_READINESS.md` warnings about scope limitations
- Inclusion in the project name, branding, or marketing of the Taiwan UI logo / mark (covered by trademark, not by sponsorship)
- Influence over open-source decisions that conflict with the project's stated mission

## Grant program acknowledgments

If Taiwan UI receives grants from Taiwan-based programs (g0v, OCF, moda, etc.), those are listed in `GRANTS.md` (separate from individual sponsorship) with grant amount, source, and what was delivered.
