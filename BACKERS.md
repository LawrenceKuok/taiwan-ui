## Updating this file

This file is updated within 7 days of any new sponsorship taking effect. If you're sponsoring and not listed (or want to opt out of public listing), open an issue or email `sponsor@taiwan-ui.dev`.

Listing format:

```
- [Sponsor name](https://link) — tier, optional one-line description, [start date]
```

For organizations: include logo file path under `public/sponsors/<slug>.svg` once submitted.

For individuals: name + optional Twitter / GitHub handle is fine; some sponsors prefer to be listed anonymously.
